一、GDP 的含义与三种形态

国内生产总值（GDP）是按市场价格计算的一个国家（或地区）在一定时期内生产活动的最终成果，用最终产品计量。有三种形态：

形态说明
价值形态所有常住单位增加值之和 = 总产出 - 中间投入
收入形态生产要素收入 + 非生产要素收入（间接税、折旧等）
产品形态最终消费 + 资本形成 + 净出口（货物与服务）

二、GDP 的核算方法 必考

方法构成公式
支出法消费 C、投资 I、政府购买 G、净出口（X-M）GDP = C + I + G + (X - M)
收入法（理论）工资+利息+租金+利润+间接税和企业转移支付+折旧+统计误差见左
收入法（我国实践）劳动者报酬、生产税净额、固定资产折旧、营业盈余四者之和

三、储蓄—投资恒等式

从总需求=总供给推导，存在部门间恒等式（注意是"事后的均衡等式"，不必然等于意愿投资）：

经济恒等式（I = S + …）
两部门I = S　（即 C + I = C + S）
三部门I = S + (T - G)
四部门I = S + (T - G) + (M - X)
记忆：支出法 GDP 四块——C、I、G、NX；投资恒等：两部门 I=S，三部门加(T-G)，四部门再加(M-X)。
