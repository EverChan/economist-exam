第 1 节：国民收入核算

本节学习目标

  • 掌握凯恩斯消费理论的三个假设 必考
  • 理解消费函数 C = α + βY 与储蓄函数，及 APC、MPC、APS、MPS 的关系
  • 了解生命周期理论与持久收入理论

一、凯恩斯消费理论（三假设） 必考

  • 边际消费倾向递减规律：收入增，消费增，但消费占比递减；0 < MPC < 1。
  • 收入是决定消费的最重要因素。
  • 平均消费倾向随收入增加而下降：APC 可能 >、=、< 1，且 MPC < APC。

二、消费函数与储蓄函数

消费函数 C = α + βY（α 自发消费，β 边际消费倾向）；储蓄函数 S = -α + (1 - β)Y。二者互为补数，C + S = Y。

指标含义关系
平均消费倾向 APC消费/收入APC + APS = 1
平均储蓄倾向 APS储蓄/收入
边际消费倾向 MPC增加一单位收入增加的消费MPC + MPS = 1
边际储蓄倾向 MPS增加一单位收入增加的储蓄
记忆：MPC < APC；MPC + MPS = 1；APC + APS = 1。MPC（边际）必在 0~1 之间。

三、生命周期与持久收入理论

  • 生命周期理论（莫迪利安尼）：消费取决于家庭所处生命周期阶段；长期 MPC 稳定。
  • 持久收入理论（弗里德曼）：消费由持久收入决定，是持久收入的稳定函数。
