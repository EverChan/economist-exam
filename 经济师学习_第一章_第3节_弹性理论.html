一、需求价格弹性 本章最重要 · 每年必考

1. 什么是需求价格弹性

需求价格弹性衡量的是：价格变动1%时，需求量变动百分之几。它反映需求量对价格变动的敏感程度。

大白话：涨价了，你买不买？如果"涨一点就不买了"→ 弹性大；如果"涨多少都得买"→ 弹性小。

2. 计算公式 必考

需求价格弹性系数 Ed = 需求量的相对变动 / 价格的相对变动

公式：Ed = (ΔQ / Q) ÷ (ΔP / P)
其中 ΔQ 是需求量变化量，Q 是原需求量；ΔP 是价格变化量，P 是原价格。
注意：由于需求量与价格反方向变动，ΔQ 和 ΔP 符号相反，所以 Ed 通常为负值。但习惯上我们取绝对值来比较弹性大小。

3. 需求价格弹性的五种类型 高频考点 · 必背

类型 弹性系数 含义 典型商品
富有弹性 Ed > 1 需求量变动幅度 > 价格变动幅度（价格小变，需求大变） 奢侈品、高档耐用品（珠宝、旅游）
缺乏弹性 Ed < 1 需求量变动幅度 < 价格变动幅度（价格大变，需求小变） 必需品（粮食、食盐、药品）
单位弹性 Ed = 1 需求量变动幅度 = 价格变动幅度（同步变动） 理论上的特殊情况，现实中少见
完全无弹性 Ed = 0 无论价格怎么变，需求量都不变（需求曲线垂直） 救命药、不可替代的必需品
完全有弹性 Ed = ∞ 价格微小变动，需求量无限变动（需求曲线水平） 完全竞争市场中的单个企业
记忆技巧：
"富有" = 弹性大 = 敏感 = 奢侈品（买不买都行，贵了就不买）
"缺乏" = 弹性小 = 不敏感 = 必需品（不买不行，涨多少都得买）
"完全无" = 死活不变 = 救命药
"完全有" = 一点就炸 = 完全竞争

4. 影响需求价格弹性的因素 多选题常考

因素 说明 对弹性的影响
替代品数量 替代品越多，消费者选择余地越大 替代品多 → 弹性大
商品用途广泛性 用途越广，价格变动影响越大 用途广 → 弹性大
时间长短 时间越长，消费者越能调整行为 长期 > 短期（长期弹性大）
商品重要性 生活必需品 vs 非必需品 必需品 → 弹性小；非必需品 → 弹性大
消费支出占比 该商品支出占总支出的比重 占比大 → 弹性大（如买房）；占比小 → 弹性小（如食盐）
例子对比：
食盐：替代品少、用途单一、必需、支出占比小 → 缺乏弹性（Ed < 1）
黄金首饰：替代品多（可买其他投资品）、非必需、支出占比大 → 富有弹性（Ed > 1）

5. 价格弹性与总收益的关系 计算题常考

总收益 = 价格 × 销量。价格变动会影响销量，而销量变化取决于弹性：

弹性类型 降价的影响 涨价的影响
富有弹性（Ed > 1） 销量大增 → 总收益增加 销量大减 → 总收益减少
缺乏弹性（Ed < 1） 销量微增 → 总收益减少 销量微减 → 总收益增加
核心逻辑（必记）：
富有弹性 → "薄利多销"有效 → 降价能增收（奢侈品打折促销）
缺乏弹性 → "薄利多销"无效 → 涨价能增收（粮食、药品不能随便降价）

二、需求收入弹性 高频考点

1. 定义与公式

需求收入弹性衡量的是：收入变动1%时，需求量变动百分之几。

公式：Ey = (ΔQ / Q) ÷ (ΔY / Y)
其中 Y 表示收入（Income），Q 表示需求量。

2. 需求收入弹性的分类 必背

弹性系数 类型 含义 典型商品
Ey > 1 奢侈品 需求增长幅度 > 收入增长幅度 珠宝、豪车、旅游
0 < Ey < 1 必需品 需求增长幅度 < 收入增长幅度（收入增加也多买一点，但增幅小） 粮食、服装、日用品
Ey = 1 收入单位弹性 需求增长幅度 = 收入增长幅度 理论特殊情况
Ey < 0 低档品 收入增加，需求反而减少 公交卡、廉价方便面、二手商品
Ey = 0 收入无弹性 收入变动不影响需求 火柴、食盐（极端情况）
关键记忆点：
Ey > 0 → 正常品（收入↑需求↑），其中 Ey > 1 是奢侈品，0 < Ey < 1 是必需品
Ey < 0 → 低档品（收入↑需求↓）
与第1节的联系：收入弹性正负决定了商品是"正常品"还是"低档品"，这和第1节讲的收入因素对需求的影响完全一致。

三、需求交叉弹性 高频考点

1. 定义与公式

需求交叉弹性衡量的是：商品Y的价格变动1%时，商品X的需求量变动百分之几。它用来判断两种商品之间的关系。

公式：Exy = (ΔQx / Qx) ÷ (ΔPy / Py)
X 的需求量变化率 ÷ Y 的价格变化率。

2. 需求交叉弹性的分类 必背

弹性系数 商品关系 含义 典型例子
Exy > 0 替代品 Y涨价 → 消费者转向X → X需求增加（同方向变动） 咖啡与茶、牛肉与猪肉
Exy < 0 互补品 Y涨价 → X需求也减少（反方向变动） 汽车与汽油、打印机与墨盒
Exy = 0 无关品 Y的价格变动不影响X的需求 面包与鞋子
判断技巧：
交叉弹性 正数 → 替代品（Y涨了你去买X，X需求↑，同向）
交叉弹性 负数 → 互补品（Y涨了X也少买，反向）
交叉弹性 零 → 无关
与第1节的联系：这就是第1节"替代品价格"和"互补品价格"对需求影响的量化版本。

四、供给价格弹性

1. 定义与公式

供给价格弹性衡量的是：价格变动1%时，供给量变动百分之几。

公式：Es = (ΔQs / Qs) ÷ (ΔP / P)
由于供给量与价格同方向变动，Es 通常为正值。

2. 供给价格弹性的类型

类型 弹性系数 含义
富有弹性 Es > 1 供给量变动幅度 > 价格变动幅度（供给敏感）
缺乏弹性 Es < 1 供给量变动幅度 < 价格变动幅度（供给不敏感）
单位弹性 Es = 1 供给量变动幅度 = 价格变动幅度
完全无弹性 Es = 0 供给曲线垂直，价格怎么变供给都不变（如绝版艺术品）
完全有弹性 Es = ∞ 供给曲线水平，价格微小变动供给无限变动

3. 影响供给价格弹性的因素 多选题常考

因素 说明 对弹性的影响
时间 短期产能固定，长期可调整 长期 > 短期（长期弹性大）
生产周期 生产周期越长，调整越慢 周期长 → 弹性小（如房地产）
生产成本 增产导致成本大幅上升则弹性小 成本上升快 → 弹性小
资源供给 生产所需资源是否充足 资源充足 → 弹性大；资源稀缺 → 弹性小
例子对比：
农产品：生产周期长（一季庄稼几个月）、受自然条件限制 → 供给缺乏弹性
工业流水线产品：产能可快速调整、技术成熟 → 供给富有弹性

五、四种弹性总对比 考前必看

弹性类型 衡量什么 公式 系数符号 核心用途
需求价格弹性 需求量对自身价格的敏感度 Ed = (ΔQ/Q)/(ΔP/P) 负值（取绝对值） 判断涨价/降价策略
需求收入弹性 需求量对收入的敏感度 Ey = (ΔQ/Q)/(ΔY/Y) 正：正常品
负：低档品		 区分商品档次
需求交叉弹性 X需求量对Y价格的敏感度 Exy = (ΔQx/Qx)/(ΔPy/Py) 正：替代品
负：互补品		 判断商品关系
供给价格弹性 供给量对价格的敏感度 Es = (ΔQs/Qs)/(ΔP/P) 正值 判断供给调整能力

高频考点速记卡

  • 需求价格弹性 Ed：取绝对值。Ed > 1 富有弹性（奢侈品），Ed < 1 缺乏弹性（必需品），Ed = 0 完全无弹性（救命药）
  • 富有弹性 → 降价增收；缺乏弹性 → 涨价增收。这就是"薄利多销"只对弹性大的商品有效的原因
  • 影响需求价格弹性的因素：替代品数量、用途广泛性、时间长短、商品重要性、支出占比
  • 需求收入弹性 Ey：Ey > 0 正常品（Ey > 1 奢侈品，0 < Ey < 1 必需品），Ey < 0 低档品
  • 需求交叉弹性 Exy：正数 = 替代品，负数 = 互补品，零 = 无关品
  • 供给价格弹性 Es：正值。影响因素：时间、生产周期、生产成本、资源供给
  • 口诀：收入弹正正常品、负低档品；交叉弹正替代品、负互补品。价格弹负取绝对值比较大小

练习题（6题）

1.（单选）某商品价格上升5%，需求量下降10%。该商品的需求价格弹性为：




答案：B

解析：Ed = |ΔQ/Q| ÷ |ΔP/P| = 10% ÷ 5% = 2。Ed = 2 > 1，所以是富有弹性。计算时取绝对值，不看负号。

2.（单选）下列商品中，需求价格弹性最大的是：




答案：C

解析：弹性大小看"替代品多少 + 必需程度 + 支出占比"。
食盐（A）：替代品少、必需、支出占比极小 → 弹性极小
大米（B）：必需品、替代品少 → 弹性小
高档化妆品（C）：非必需、替代品多（不同品牌/可不用）、支出占比大 → 弹性最大
救命药（D）：完全无弹性（Ed = 0），价格再贵也得买

3.（单选）某商品需求缺乏弹性，如果企业想增加总收益，应该：




答案：B

解析：缺乏弹性（Ed < 1）意味着价格变动大但需求量变动小。涨价 → 销量只微减 → 总收益（P×Q）增加。降价 → 销量只微增 → 总收益减少。"薄利多销"只对富有弹性的商品有效，对缺乏弹性的商品反而吃亏。

4.（单选）某商品需求收入弹性系数 Ey = -0.5，说明该商品是：




答案：C

解析：Ey < 0 表示收入增加时需求反而减少，这是低档品的特征。Ey > 1 奢侈品，0 < Ey < 1 必需品，Ey = 0 收入无弹性。-0.5 说明收入每增加1%，需求减少0.5%，属于低档品。

5.（单选）商品X和商品Y的需求交叉弹性系数 Exy = -1.2，说明X和Y是：




答案：B

解析：Exy < 0（负数）→ 互补品。Y的价格变动和X的需求量反方向变动：Y涨价 → X需求减少。-1.2 表示Y涨价1%，X需求减少1.2%。如果是替代品，Exy > 0；如果是无关品，Exy = 0。

6.（多选）下列哪些因素会使某商品的需求价格弹性增大（变得更富有弹性）？




答案：ABD

解析：
A. 替代品增多 → 消费者选择余地大 → 弹性增大 ✓
B. 时间变长 → 消费者有更多时间调整行为 → 弹性增大 ✓
C. 成为必需品 → 不买不行 → 弹性减小 ✗（方向相反）
D. 支出占比增大 → 价格变动对生活影响大 → 消费者更敏感 → 弹性增大 ✓
