第 3 节：国际商务谈判与合同

一、进出口业务程序

出口业务程序：备货 → 催证、审证、改证 → 租船订舱 → 投保 → 报检报关 → 装船 → 制单结汇。

进口业务程序：开立信用证 → 租船订舱 → 投保 → 审单付款 → 报关提货 → 验收。

二、国际贸易支付方式

方式信用基础说明
汇付（Remittance）商业信用电汇T/T、信汇M/T、票汇D/D
托收（Collection）商业信用银行代收：付款交单D/P、承兑交单D/A
信用证（L/C）银行信用银行承诺付款，最核心、最常用

风险比较：对出口方，信用证风险最低（银行信用）；托收中 D/A 风险高于 D/P；预付货款（汇付）对出口方最有利。高频考点

三、报价核算（FOB / CFR / CIF 换算）

  • CFR = FOB + 运费 F
  • CIF = CFR + 保险费 = (FOB + F) / (1 - 保险费率×投保加成)
  • FOB = CIF - 运费 - 保险费

练习题（5题）

1.（单选）出口业务程序的第一步是：




答案：A

解析：出口流程以备货（落实货源）为第一步，最后制单结汇收汇。

2.（单选）信用证（L/C）的信用基础是：




答案：C

解析：信用证是银行作出的付款承诺，属银行信用，是国际贸易中最核心的结算方式。

3.（多选）托收方式包括：




答案：AB

解析：托收分为付款交单 D/P 和承兑交单 D/A；L/C 是信用证、T/T 是汇付，不属托收。

4.（单选）对出口方而言，下列支付方式风险最低的是：




答案：C

解析：信用证是银行信用，对出口方收款最有保障、风险最低。

5.（单选）CFR 与 FOB 的价格关系为：




答案：B

解析：CFR 在 FOB 基础上加上运费，即 CFR = FOB + F。
