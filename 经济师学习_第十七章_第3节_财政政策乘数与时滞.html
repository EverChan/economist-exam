一、财政乘数（b 为边际消费倾向，0<b<1） 必考

乘数公式符号
政府购买支出乘数Kg = 1 / (1 - b)正
税收乘数Kt = -b / (1 - b)负（增税抑制）
转移支付乘数Ktr = b / (1 - b)正
平衡预算乘数Kb = 1正
记忆：政府购买乘数 = 1/(1-b)；税收乘数 = -b/(1-b)；转移支付乘数 = b/(1-b)；平衡预算乘数恒为 1。|政府购买乘数| > |转移支付乘数| > |税收乘数|。

二、财政政策时滞

类别构成
内部时滞认识时滞、行政时滞（发生在决策前）
外部时滞决策时滞、执行时滞、效果时滞（决策后到见效）
例子：若 b=0.8，则政府购买乘数=5、税收乘数=-4、转移支付乘数=4、平衡预算乘数=1。增加 100 亿政府购买，国民收入增 500 亿。

练习题（5题）

1.（单选）若边际消费倾向 b=0.8，则政府购买支出乘数为：




答案：B

解析：Kg = 1/(1-b) = 1/0.2 = 5。政府购买乘数恒为正且最大。

2.（单选）平衡预算乘数等于：




答案：D

解析：平衡预算乘数恒为 1，即政府收支等量增加时国民收入同量增加。

3.（多选）下列财政乘子中，数值为正的有：





答案：ACD

解析：政府购买乘数、平衡预算乘数为正；转移支付乘数为正；税收乘数为负（增税抑制）；汇率乘数非财政乘数。

4.（多选）财政政策时滞中，属于"内部时滞"的有：





答案：AB

解析：内部时滞=认识时滞+行政时滞（决策前）；决策、执行、效果时滞属外部时滞（CDE错）。

5.（真题风格）（计算）若 b=0.75，政府同时增支 200 亿元、增税 200 亿元（平衡预算），国民收入最终变动约为：




答案：B

解析：平衡预算乘数=1，收支等额变动 200 亿，国民收入变动 = 1 × 200 = 增加 200 亿。也可用 Kg=4、Kt=-3 验证：4×200 + (-3)×200 = 200。
