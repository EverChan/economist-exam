第一章：市场需求、供给与均衡价格

第 1 节 / 共 3 节 · 需求与供给 | 预计学习时长 40 分钟

本章进度 1/3

本节学习目标

  • 理解需求的定义，区分"需求量变动"与"需求变动" 高频考点
  • 理解供给的定义，区分"供给量变动"与"供给变动" 高频考点
  • 掌握影响需求和供给的非价格因素
  • 记住需求曲线和供给曲线的形状与方向

一、需求理论

1. 什么是需求

需求是指消费者在一定时期内，在各种可能的价格水平上愿意而且能够购买的某种商品的数量。

关键点："愿意" + "能够"缺一不可。你想买一套别墅（愿意），但买不起（不能够），这不叫需求，叫需要或欲望。只有你既想买又买得起，才是经济学意义上的有效需求。

2. 需求曲线 必考

需求曲线反映价格（P）与需求量（Q）之间的关系：

  • 纵轴是价格 P，横轴是需求量 Q
  • 需求曲线向右下方倾斜（从左上到右下）
  • 需求定理：价格上升 → 需求量下降；价格下降 → 需求量上升（反方向变动）
记忆口诀：需求曲线"右下倾"——价格越低，买的人越多。这和日常直觉一致：打折了多买点。

3. 需求量的变动 vs 需求的变动 高频考点 · 每年必出

这是本章最容易混淆也是考试最爱考的 distinction，务必记牢：

对比项 需求量的变动 需求的变动
引起原因 商品本身价格变动 非价格因素变动
曲线表现 沿同一条需求曲线移动（点在曲线上滑动） 整条需求曲线平移（左移或右移）
方向 价格↑→需求量↓（沿曲线向上移）
价格↓→需求量↑（沿曲线向下移）		 右移 = 需求增加
左移 = 需求减少
例子：
咖啡涨价了，你少买了两杯 → 这是需求量的变动（本身价格引起，沿曲线移动）
你的工资涨了，咖啡没涨价但你多买了 → 这是需求的变动（收入引起，整条曲线右移）
茶降价了，你不喝咖啡改喝茶了 → 这是需求的变动（替代品价格引起，咖啡需求曲线左移）

4. 影响需求变动的因素（非价格因素） 多选题常考

因素 说明 对需求的影响
消费者偏好 突然喜欢上某样东西 偏好↑ → 需求右移
消费者收入 收入增加，购买力增强 正常品：收入↑ → 需求右移
低档品：收入↑ → 需求左移
替代品价格 能互相替代的商品（咖啡 vs 茶） 替代品涨价 → 本商品需求右移
互补品价格 配套使用的商品（汽车 vs 汽油） 互补品涨价 → 本商品需求左移
预期 预期未来价格会涨 预期涨价 → 现在需求右移（提前买）
消费者数量 人口增加、市场扩大 人数↑ → 需求右移
考试技巧：看到题目说"价格变动"→ 需求量的变动（沿曲线移动）；看到"收入/偏好/替代品/互补品/预期"→ 需求的变动（曲线平移）。记住这个判断逻辑，选择题秒选。

二、供给理论

1. 什么是供给

供给是指生产者在一定时期内，在各种可能的价格水平上愿意而且能够提供的某种商品的数量。

关键点：和需求一样，"愿意" + "能够"缺一不可。工厂有产能但不想卖（价格太低不划算），不算供给。

2. 供给曲线 必考

  • 供给曲线向右上方倾斜（从左下到右上）
  • 供给定理：价格上升 → 供给量上升；价格下降 → 供给量下降（同方向变动）
记忆口诀：供给曲线"右上倾"——价格越高，卖方越愿意多卖。也很好理解：利润高了，当然多生产。
对比记忆：
需求曲线 → 右下倾（价格↓ 买得↑）
供给曲线 → 右上倾（价格↑ 卖得↑）
两者方向相反，这是均衡价格能够形成的基础。

3. 供给量的变动 vs 供给的变动 高频考点

逻辑和需求完全一样，只是主体从消费者变成了生产者：

对比项 供给量的变动 供给的变动
引起原因 商品本身价格变动 非价格因素变动
曲线表现 沿同一条供给曲线移动 整条供给曲线平移
方向 价格↑→供给量↑（沿曲线向上移） 右移 = 供给增加
左移 = 供给减少

4. 影响供给变动的因素（非价格因素） 多选题常考

因素 说明 对供给的影响
生产成本 原材料涨价、人工成本上升 成本↑ → 供给左移（减少）
生产技术 技术进步提高效率 技术↑ → 供给右移（增加）
相关产品价格 替代品的利润变化 替代品涨价 → 本品供给左移（转去生产替代品）
预期 预期未来价格会涨 预期涨价 → 现在供给左移（囤货等高价再卖）
生产者数量 更多企业进入市场 企业↑ → 供给右移
例子：
牛奶收购价提高了，牧场多养了牛 → 供给量的变动（本身价格引起）
饲料涨价了，牛奶没涨价但牧场减产了 → 供给的变动（成本引起，左移）
引入了自动化挤奶设备，效率提高了 → 供给的变动（技术引起，右移）

高频考点速记卡

  • 需求曲线右下倾，供给曲线右上倾——方向相反
  • 需求定理：价格与需求量反方向变动；供给定理：价格与供给量同方向变动
  • "本身价格变动" → 量的变动（沿曲线移动）；"非价格因素变动" → 曲线变动（整条平移）
  • 需求的影响因素：偏好、收入、替代品价格、互补品价格、预期、消费者数量
  • 供给的影响因素：生产成本、生产技术、相关产品价格、预期、生产者数量
  • 正常品：收入↑需求↑；低档品：收入↑需求↓
  • 替代品：替代品涨价 → 本品需求↑；互补品：互补品涨价 → 本品需求↓

练习题（5题）

1.（单选）某商品价格下降，导致该商品需求量增加。这种现象属于：




答案：B

解析：商品本身价格下降引起的需求量增加，属于需求量的变动，表现为沿同一条需求曲线向右下方移动。非价格因素引起的才是"需求的变动"。

2.（单选）消费者收入增加，对低档品的需求会：




答案：B

解析：低档品是指收入增加时需求反而减少的商品（如公交卡、廉价方便面）。收入增加 → 消费者转向更好的替代品 → 低档品需求减少，需求曲线左移。与低档品相对的是正常品（收入↑需求↑）。

3.（单选）下列因素中，不会引起供给曲线移动的是：




答案：C

解析：商品本身价格变动引起的是供给量的变动（沿曲线移动），不是供给曲线的移动（平移）。A、B、D都是非价格因素，会引起供给曲线平移。

4.（多选）下列哪些因素会引起某商品需求的增加（需求曲线右移）？




答案：ABD

解析：
A. 正常品收入↑ → 需求右移 ✓
B. 替代品涨价 → 消费者转向本品 → 需求右移 ✓
C. 互补品涨价 → 两者搭配使用，一起买才划算，互补品贵了本品需求反而左移 ✗

5.（单选）汽油价格上涨，对汽车需求的影响是：




答案：B

解析：汽油和汽车是互补品（配套使用）。汽油涨价 → 用车成本上升 → 汽车需求减少 → 需求曲线左移。注意：这不是汽车本身价格变动，所以是"需求的变动"而非"需求量的变动"，排除C和D。
