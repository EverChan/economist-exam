一、投资乘数

投资乘数 k = ΔY / ΔI = 1 / (1 - β) = 1 / MPS。β（边际消费倾向）越大，乘数越大。例：β = 0.8 时，k = 5。

二、财政政策乘数

乘数公式符号/结论
政府购买乘数 K_G1 / (1 - β)正数，与国民收入同向
税收乘数 K_T-β / (1 - β)负数，与国民收入反向；β=0.8 时为 -4
平衡预算乘数 K_BK_G + K_T = 1恒等于 1（扩张效应）
记忆：政府购买乘数 > |税收乘数|，故增支比减税更能拉动经济；平衡预算乘数恒为 1。β 越大，乘数越大。

解析：投资乘数 k = 1/(1-β) = 1/(1-0.8) = 5。即投资增加 100 亿可带动收入增加 500 亿。

解析：平衡预算乘数 K_B = K_G + K_T = 1/(1-β) + [-β/(1-β)] = 1，恒等于 1，仍具扩张效应。
